# FinalCif 中文版：GUI 与 CheckCIF 体验改进任务书

状态：已实施（2026-11-24）
适用版本：FinalCif 中文版（v180 基线）
维护：Honghao Cao，honghaocao838@gmail.com

## 1. 背景

当前版本已完成界面汉化、主表列说明、悬停提示和 545 条 PLAT 警报中文解释。日常使用中仍有两个效率瓶颈：

- 主表通常有 800 至 1500 行，找缺值、找异常、找某个中文概念对应的 CIF 键，只能靠肉眼和键名搜索。
- 在线 CheckCIF 只有提交和结果两种反馈，无法判断请求是否到达服务器、已等待多久、失败是网络问题还是服务器问题。

本任务补齐这两块，并顺带处理 CIF 字典帮助的中文化和必填项筛选。所有改动限于界面与交互，不改变 CIF 保存逻辑。

## 2. 目标

- 主表能在 3 秒内定位到需要处理的项。
- 在线 CheckCIF 全过程有明确状态、耗时和失败原因。
- 常用 CIF 键的帮助有中文。
- 能按“必填”和“CheckCIF 提到”筛选待处理项。

## 3. 范围

本期做：

- 主表过滤条、中文别名搜索、校验汇总
- CheckCIF 结果摘要
- 在线 CheckCIF 状态反馈、计时、连通性测试、取消
- 左侧面板折叠与布局记忆
- 行右键菜单补全
- CIF 字典帮助汉化首批 150 条
- 必填项过滤（人工清单加 CheckCIF 反推）

本期不做：

- 编辑撤销栈
- 深色模式
- 字典帮助剩余 584 条（列入 M6）
- 多语言界面切换

## 4. 功能需求

### 4.1 A 主表过滤条

A1. 在主表说明条下方增加一行：状态下拉框、搜索框、结果计数。

A2. 状态下拉选项：

- 全部
- 未填（`?`）
- 数据源已填（绿）
- 校验错误（红底）
- 有响应模板（浅蓝）

A3. 搜索框匹配键名、中文别名、当前值，大小写不敏感。

A4. 计数显示“显示 123 / 1042 行”。

A5. 过滤使用 `setRowHidden`，不重建模型，不销毁单元格控件。

A6. 条件变化后 200 ms 内渲染完成，2000 行以内在 100 ms 内完成。

验收：

- 1000 行以上的 CIF 选择“未填”后只剩缺值行
- 清空条件恢复全部
- 切换标签页后条件保留

### 4.2 B 中文别名搜索

B1. 新增 `finalcif/datafiles/key_aliases.json`，收录常用键的中文别名，首期 120 至 150 条。

示例：

```json
{
  "_diffrn_ambient_temperature": ["温度", "测试温度"],
  "_space_group_name_H-M_alt": ["空间群"],
  "_chemical_formula_sum": ["分子式"],
  "_cell_length_a": ["晶胞参数", "a 轴"]
}
```

B2. 搜索同时匹配键名、别名、当前值；别名命中时高亮对应行。

B3. 别名表缺失或损坏时退化为原有关键字搜索，不报错。

验收：

- 搜索“温度”定位到 `_diffrn_ambient_temperature`
- 搜索“空间群”定位到空间群相关键
- 搜索不存在的词显示 0 行且不卡顿

### 4.3 C 校验状态汇总

C1. 主表底部显示“N 项格式不合法”，N 为当前红底单元格数。

C2. 点击跳到第一条不合法项并选中该行。

C3. 无错误时显示“格式校验通过”。

验收：

- 自定义数据列输入非法值后计数变为 1，点击可定位
- 修正后计数归零

### 4.4 D CheckCIF 结果摘要

D1. 在线或离线 CheckCIF 完成后，在结果页顶部显示各级警报数量，例如 `A 2 / B 7 / C 15 / G 3`。

D2. 数字可点击，展示该级别警报清单（PLAT 编号、级别、摘要），点击单条打开中文解释。

D3. 数据来源：在线结果复用现有 HTML 解析，离线结果从 PLATON 输出解析。

D4. 解析失败时隐藏摘要区，不影响报告显示。

验收：

- 摘要数量与 HTML 报告中的警报数量一致
- 点击 A 级数字只显示 A 级条目

### 4.5 E 在线 CheckCIF 状态反馈

E1. 状态与文案：

| 状态 | 文案 |
|---|---|
| 空闲 | 未运行 |
| 准备 | 正在准备 CIF |
| 已提交 | 已提交，等待服务器返回（已等待 12 s） |
| 成功 | 完成，用时 18.4 s |
| 失败 | 失败：网络不可达 / 服务器超时 / 服务器返回 503 / URL 无效 |
| 取消 | 已取消 |

E2. 提交后每 0.5 s 刷新等待时长，显示在日志区与结果页顶部。

E3. 等待超过 60 s 追加提示“服务器较忙，通常需要 10 至 60 s，可继续等待或取消”。

E4. 失败原因按异常类型区分：DNS 或连接失败、TLS 错误、读超时、HTTP 4xx/5xx（含状态码）、URL 缺少 schema。

E5. 结果生成后记录时间戳；若当前 CIF 内容与生成结果时不同，显示“CIF 已修改，结果可能过期”。

验收：

- 断网时 5 s 内显示“网络不可达”，不出现长时间无响应
- 正常网络下等待秒数递增，完成后停止

### 4.6 F 连通性测试

F1. CheckCIF 页增加“测试连接”按钮。

F2. 对服务器根地址发起 GET，超时 5 s，异步执行，不阻塞界面。

F3. 结果展示：

- 可连通：显示“可连通，延迟 320 ms，HTTP 200”
- 不可连通：区分 DNS 失败、连接超时、TLS 失败

F4. 失败时给出可操作建议：检查代理、检查选项中的服务器地址、用浏览器打开确认。

F5. 按钮 3 s 内不可重复点击。

验收：

- 正常网络显示延迟
- 断网显示失败原因
- 把选项中的 URL 改为无效地址后提示 URL 无效

### 4.7 G 取消在线请求

G1. 等待期间“在线 CheckCIF”按钮变为“取消”。

G2. 取消后立即恢复按钮状态，标记“已取消”，丢弃迟到的结果。

G3. 说明：HTTP 请求本身无法中断，取消表示停止等待、不采用结果，后台线程允许自行结束。

验收：

- 提交后 2 s 内点击取消，界面立即恢复，不写入结果文件

### 4.8 H 左侧面板折叠与布局记忆

H1. “仪器模板”“报告模板”两组改为可折叠，默认折叠。

H2. 折叠状态、主表列宽、分隔条位置写入设置，下次启动恢复。

H3. 提供“恢复默认布局”。

验收：

- 折叠两组后重启程序仍为折叠
- 调整列宽后重启保持

### 4.9 I 行右键菜单补全

I1. 行右键增加：复制键名、复制当前值、查看该键帮助、跳到数据来源页对应项。

I2. 分隔行和空行不显示菜单。

验收：

- 任意正常行四项均可用
- 复制内容与单元格一致

### 4.10 J CIF 字典帮助汉化

J1. 现状与范围

`finalcif/cif/core_dict.py` 共 734 个条目、28.3 万字符。每条是一段 HTML：`<pre><h2>_键名</h2>` 加定义正文，再加 `<h4>Type:</h4>` 与 `<h4>Limits:</h4>`。当前全部为英文。

J2. 交付物

新增 `finalcif/datafiles/core_dict_zh.json`，键为 CIF 键名，值为中文 HTML。`show_keyword_help` 优先取中文，未命中回退英文原文。

J3. 翻译规则

- 只翻正文；键名、公式、单位、参考文献、`Type` 与 `Limits` 字段名保持不变
- 保留全部 HTML 标签与转义（`<pre>`、`&amp;`、上下标标记 `^` `~`）
- CIF 语法符号（下划线键名、方括号、引号）不得改动
- 术语与现有词表一致：原子位点、各向异性位移参数、标准不确定度（s.u.）、占有率、衍射点

J4. 分批实施

- 首批 150 条常用键：晶胞、空间群、原子位点、ADP、R 值、实验条件
- 第二批剩余 584 条
- 多 agent 并行翻译，主会话负责合并与校验

J5. 验收标准

- 选中已翻译条目点“帮助”显示中文，上下标与公式渲染正常
- 未翻译条目显示英文原文，并在标题后标注“（暂无中文）”
- 词典文件缺失或损坏时全部回退英文，不影响启动
- 帮助窗口宽度、换行与改动前一致

J6. 风险

- HTML 标签或转义损坏会导致排版错乱或丢字，合并时需做标签配对与键集合校验
- 公式中的 `^` `~` 是 CIF 排版标记，容易被误当普通符号处理

工作量：首批 0.5 至 1 天，全量再 1 至 1.5 天。

### 4.11 K 必填项过滤

K1. 新增 `finalcif/datafiles/key_required.json`，约 40 条，分两级。

```json
{
  "_cell_length_a": {"level": "required", "note": "晶胞参数 a"},
  "_refine_ls_R_factor_gt": {"level": "required", "note": "R1 [I > 2σ(I)]"},
  "_refine_ls_abs_structure_Flack": {"level": "recommended", "note": "非中心对称结构需要"}
}
```

覆盖范围：晶胞参数、空间群、分子式、Z、R1 与 wR2、辐射与波长、测试温度、衍射点与参数统计、CCDC 与 COD 编号、吸收校正。

K2. 过滤条新增选项：“必填未填”“必填（全部）”“CheckCIF 提到”。

K3. “必填未填”判定：键在 required 清单中，且 CIF 值、数据源、自定义三列均为空、`?` 或 `.`。

K4. “CheckCIF 提到”：解析最近一次 CheckCIF 结果文本中的 `_key` 形式 token，与主表键匹配。结果需记录生成时间；无结果时该选项禁用，并提示先运行 CheckCIF。

K5. 界面反馈：过滤下拉旁显示计数，例如“必填未填 6 项”；点击计数跳到第一条；行上可加提示图标，说明缺失级别。

K6. 维护策略：清单随安装包更新。允许用户在配置目录放覆盖副本，程序优先读用户副本。

K7. 验收标准

- 打开缺项较多的 CIF，选择“必填未填”只显示清单内的缺失键
- 补齐后计数实时归零
- 未跑 CheckCIF 时“CheckCIF 提到”不可用且有提示
- 清单缺失或 JSON 损坏时该选项隐藏，原有过滤不受影响
- 必填清单只做提示，不阻止保存

K8. 风险

- 必填要求随期刊和年份变化，清单需注明依据与更新日期
- 从警报文本提取键名可能误匹配，匹配结果标注“来自 CheckCIF 文本”，不做强判断

工作量：约 1 天。

## 5. 非功能要求

- 不改变 CIF 保存内容，保存结果仍为纯 ASCII。
- 不新增第三方依赖，使用现有 `requests`、`QThread`、`QTimer`。
- 新增文案为中文，同时保留英文源串，便于同步上游。
- 在线功能失败不得影响本地编辑、保存和离线 CheckCIF。
- 过滤与搜索不得销毁表格控件，避免编辑焦点丢失。
- 字典与必填清单加载失败时全部降级，不阻断启动。

## 9. 风险与未决项

- 表格使用 `setIndexWidget`，隐藏行时需确认控件不抢占键盘焦点。
- `requests` 无法真正中断请求，取消只能做到停止等待、丢弃结果，界面文案需说明。
- checkcif.iucr.org 有频率限制，连通性测试不应自动频繁触发。
- 是否保存最近 10 次 CheckCIF 记录（时间、模式、用时、警报数），待定。
- 别名表首期覆盖 CIF core 常用键还是全部 core 字典，待定。
- 必填清单的依据版本（IUCr 建议、Acta Cryst. 要求、常用期刊要求）需在文件内注明。
